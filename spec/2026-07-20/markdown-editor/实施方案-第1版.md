# Markdown 文件浏览器与编辑器 - 第1版

> 日期：2026-07-20 | 版本：1 | 初始版本

## 一、概述

### 设计思路

开发一个基于 Electron + Vue 3 + Vuetify 3 的桌面端 Markdown 文件浏览器与编辑器。用户可以打开本地文件夹，在左侧文件树中浏览文件结构，在右侧编辑区域查看和编辑 Markdown 文件。支持预览模式和编辑模式切换、分屏实时预览，以及完整的文件管理功能。

### Agent 分配

本方案创建 4 个 subagent 执行任务：

| Agent | 职责 | 执行步骤 |
|-------|------|---------|
| Agent 1 | 项目初始化与 Electron 主进程 | 1. 创建项目结构 → 2. 配置 Electron 主进程 → 3. 配置安全桥接层 |
| Agent 2 | 文件系统功能模块 | 1. 实现文件树组件 → 2. 实现文件系统操作封装 → 3. 实现文件状态管理 |
| Agent 3 | Markdown 编辑器模块 | 1. 集成 CodeMirror 编辑器 → 2. 实现 Markdown 渲染器 → 3. 实现预览/编辑模式切换 |
| Agent 4 | UI 界面与设置模块 | 1. 实现主界面布局 → 2. 实现标签页管理 → 3. 实现设置持久化 |

### 执行步骤概览

**Agent 1 步骤：**
1. 创建项目目录结构和配置文件
2. 配置 Electron 主进程入口
3. 配置 preload.js 安全桥接层

**Agent 2 步骤：**
1. 实现文件树组件（支持右键菜单、拖拽、搜索过滤）
2. 封装文件系统操作 API（读取、写入、新建、删除、重命名）
3. 实现文件状态管理（Pinia store）

**Agent 3 步骤：**
1. 集成 CodeMirror 6 编辑器（语法高亮、行号、多光标）
2. 配置 markdown-it 渲染器及扩展插件
3. 实现预览模式、编辑模式、分屏模式切换

**Agent 4 步骤：**
1. 实现主界面布局（左侧文件树 + 右侧编辑区）
2. 实现多标签页管理（新建、关闭、切换）
3. 实现设置持久化（主题、窗口状态、最近文件）

   - 拖拽可以移动文件和文件夹
